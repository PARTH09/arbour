# Sample import files

Open samples from **Templates → Sample examples** or **Options → Open sample…**. Opening `/samples/` as a folder in the browser returns 404 (Next only serves files, not directory indexes).

Direct file URLs (use the port Next prints, often 3001):

| File | Purpose |
| --- | --- |
| `/samples/document-product-plan.pdf` | Text PDF → mind map |
| `/samples/document-product-plan.txt` | Plain prose document import |
| `/samples/document-hindi-outline.md` | Hindi outline |
| `/samples/document-gujarati-outline.md` | Gujarati outline |
| `/samples/whimsical-product-ideas.md` | Whimsical Markdown |

Templates → **Sample product plan** is the same content as an editable map.
